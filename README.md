E-Commerce Storefront
A modern e-commerce storefront built with React, Vite, Material UI, Redux Toolkit Query, and Strapi. The frontend displays product data managed in Strapi and includes category filters, product cards, a product-details dialog with image selection, and a responsive shopping-style interface.
Project status: The product browsing experience is connected to the Strapi API. Cart, checkout, and payment processing are not implemented yet; the current “Add To Cart” and “Buy Now” controls are UI elements for the product browsing flow.

Features
- Product catalog — loads products from the Strapi Content API.
- Category filtering — browse all products or filter by men and women.
- Product details — view a product’s title, price, description, rating, and available images in a dialog.
- Multiple product images — select image thumbnails in the product-details view.
- Responsive interface — Material UI components and responsive layouts for different screen sizes.
- Light and dark appearance — theme-aware page styling and a theme toggle in the header.
- Hero slider — promotional slides powered by Swiper.
- Motion effects — product-card animations using Framer Motion.
- Content management — create and manage product entries and media through the Strapi admin panel.
- API state management — Redux Toolkit Query handles product requests, loading/error states, and request caching.
Tech Stack
Frontend
- React 19
- Vite
- Material UI (MUI) and MUI Icons
- Redux Toolkit and Redux Toolkit Query
- React Redux
- Framer Motion
- Swiper
- Font Awesome
- Styled Components / Emotion
Backend
- Strapi 5 Content Management System
- Strapi REST API
- SQLite for local development (configurable through Strapi database settings)
- Node.js and npm
